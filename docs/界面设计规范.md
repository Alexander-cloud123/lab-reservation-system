# 界面设计规范：排课表式界面

本轮视觉重构母题是**排课表 / 楼层导视**：界面的主角是「编号 + 时段 + 状态」，而不是彩色卡片和白底盒子。所有页面共享同一套排版语法，让教室、预约、审核这些对象在不同页面里读起来像同一张表的延伸。

## 1. 设计原则

1. **编号是一等公民。** 教室编号、时段用等宽数字、浅灰底托起（`.code-block`），一眼能对齐、能比较；不再用图标方块或彩色标签替代编号。
2. **卡片不是默认容器。** 一个页面最多一条细线分区（`.section`），表格与列表去斑马纹、去投影；能一行说清的信息不单独装盒子。
3. **元信息用中文标点。** 主次信息用「楼栋 编号，类型，容量」的短句，不再用 `·` 拼接，也不再给每条信息配图标。
4. **颜色只表达状态。** 品牌蓝留给主操作与选中态；状态用 6px 圆点（`.status-dot`）加文字；日历事件用左侧 3px 色条，不整块填色。
5. **动效只回应用户动作。** 悬停只改描边与底色，不做入场动画；滚动与折叠遵循 `prefers-reduced-motion`。
6. **既有约束优先。** 不改业务规则、接口、路由与文案语义；E2E 依赖的类名与可访问性语义保留。

## 3. 公共原语（`web/src/assets/main.css`）

- `.page-head`：标题（`.page-title`）+ 说明（`.page-sub` / `.page-tip`），底部 1px 细线。
- `.section`：分区容器；首个分区无顶线，后续分区以 1px 细线上边。
- `.section-title` / `.section-note`：分区标题与小注。
- `.code-block`：22px 高、`--code-bg`、等宽数字；`.is-signal` 用于需要强调的编号（登录页 A101）。
- `.status-dot`：6px 圆点，`.is-pending` / `.is-approved` / `.is-rejected` / `.is-canceled` / `.is-today`。
- `.table-band`：表格上方细线 + 12px 内距；配合全局「去斑马纹、表头 13px、行高 46px」。
