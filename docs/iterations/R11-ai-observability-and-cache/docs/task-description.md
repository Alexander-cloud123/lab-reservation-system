# 本轮任务说明（R11 · AI 观测补全与结果缓存）

> 轮次：R11　模块：AI 能力模块　日期：2026-10-04
> 唯一依据：《需求设计文档.md》；技术规格：spec.md；协作章程：AGENTS.md

## 一、任务范围

在 AI 模块既有「可插拔降级 + 调用计数与限流」基础上，补齐两项生产能力：

1. **Token 用量与结束原因观测**：解析 OpenAI 兼容响应体的 `usage`（输入/输出/合计 token）与 `choices[0].finish_reason`，落入运行指标；并给 Prompt 打内容哈希版本号，写入降级日志与缓存 Key。
2. **AI 结果缓存**：复用项目既有 `RedisCache`，缓存合规校验 / 智能推荐 / 智能问答的**成功**结果，命中即免上游调用；降级结果永不入缓存。

## 四、明确不在本轮范围（含理由）

| 项 | 理由 |
|---|---|
| 管理端指标可视化 | 负责人本轮未选；涉前端页面改动，须按 `.agents/skills/` 前端设计规范单独走一轮 |
| 模型调用并发闸（Semaphore） | 负责人本轮未选；全站限流已把速率压在额度内，真实线程风险极低 |
| 熔断器 | 单一上游 + 本地限流已限速，收益低而纯增复杂度 |
| 429 请求内重试 | 已由实测证伪（该账号硬上限约 10 次/分钟，退避跨不过 60s 窗口，重试只会放大额度消耗），保留原结论 |
| 语义缓存 / 向量检索 / RAG / 多轮对话 / 流式输出 | 缺依赖或需求未定义，属越界 |
| 指标落库持久化 | 违背「进程内只读观测」定位，无需求支撑 |
| 解析接口（parse）结果缓存 | 输入唯一命中率极低，且 Prompt 含「今天是{日期}」后缀，跨天必然错误 |
