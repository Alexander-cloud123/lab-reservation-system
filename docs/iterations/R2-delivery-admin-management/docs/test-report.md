## 七、过程中发现并处理的问题

| # | 问题 | 根因 | 处理 |
|---|------|------|------|
| 1 | 测试脚本清理段被 `docker exec` 的 mysql 密码警告（stderr）终止 | PowerShell 5.1 在 `$ErrorActionPreference='Stop'` 下将外部命令 stderr 视为 terminating error | 改为 `$ErrorActionPreference='Continue'`（HTTP 错误已由 Invoke-Api 捕获）并抑制 stderr |
| 2 | 测试断言中文匹配（`-match '张三'`）失败 | PowerShell 5.1 读取 UTF-8 响应按 ANSI 解码，中文乱码 | 断言改用 ASCII 安全字段（`zhangsan`）验证命中 |
