# 界面设计规范：晨光玻璃（Aurora Glass）

第四轮视觉重做的母题是**晨光玻璃**：用一条从夜蓝（`#0b2a5b`）经天蓝（`#1d6fe0`）到薄荷青（`#22c3b3`）的渐变承载身份与操作，用半透明玻璃面与浮起阴影构成层次，用一抹晨光橙（`#ff9a3c`）提示「此刻」。它要解决前三版共同的问题：界面不断做减法，最后退成「白底 + 同款圆角卡片 + 同一枚灰阴影」的 SaaS 模板——这正是 2026 年被点名的 AI 默认外观。

方向来自市场调研而不是个人偏好：Muzli《Web Design Trends 2026》的结论是「Goodbye Beige, Hello Bold」（大胆渐变、饱和色回潮、micro-delight 成为区分度），Apple 的 Liquid Glass（半透明材质反射周围环境）也在同一方向。用户在三套方向样张（晨光玻璃 / 大胆色块海报 / 深色沉浸）中选定本方案。

## 1. 设计原则

1. **色彩是主角，不是点缀。** 全站有一条可辨识的渐变（`--grad`），满铺只给三处：登录/注册左栏、学生首页时刻带、管理端欢迎页 hero。其余页面用浅蓝底 + 极光背景把渐变「透」出来，而不是把渐变糊到每个元素上。
2. **层次靠材质，不靠描边。** 分区用玻璃面的半透明、内高光与浮起阴影完成；`--line` 只用于表格行与控件描边。禁止「同款圆角卡 + 同一枚灰阴影」的重复卡片堆叠。
3. **字号要做大对比。** 8 档：12 / 13 / 15 / 17 / 22 / 30，加两档展示字号 `--text-display 44px`（欢迎页首格数字）与 `--text-display-xl 56px`（登录门牌、时刻带主时钟）。标题与正文的对比目标 ≥ 3×（对齐 2026 年设计站的 4× 趋势）。
4. **数字与编号用等宽。** `--font-num` 只给门牌编号、时间、统计值与时刻带时钟；编号是这套界面里唯一稳定的「座位号」记忆点。
5. **动效只回应用户与「此刻」。** 每页一次入场编排 + 动作反馈；不做常驻呼吸、不做无限循环；`prefers-reduced-motion` 下全部压到 0.01ms。
6. **既有约束优先。** 不改业务规则、接口、路由与文案语义；E2E 依赖的类名与可访问性语义全部保留。

## 3. 材质与背景

| 层级 | 做法 |
| --- | --- |
| 页面背景 | `body` 四层叠加：左上 30% 天蓝极光、右上 26% 薄荷青光、底部 16% 晨光橙、`linear-gradient(165deg,#eaf2ff,#eef3fb 46%,#effaf8)`；`background-attachment: fixed`，滚动时极光不动 |
| 内容面 | `.surface` / `.search-card` / `.table-band`：`linear-gradient(180deg, rgba(255,255,255,.94), rgba(244,249,255,.86))` + 1px 半透明白边 + 顶部内高光 + 两段阴影（近阴影 + 远期品牌投影 + 下缘负偏移的落地投影） |
| 顶栏 / 侧栏 / 底 dock | `.glass`：半透明 + `backdrop-filter: blur(18px) saturate(140%)`；`backdrop-filter` **只允许用于这四类容器与弹窗** |
| 满铺区 | `.hero-band` / TimeBand：`var(--grad)` + 96px 极淡白网格（`--grid-ink: rgba(255,255,255,.045)`）+ 右上径向光环 + 1px 顶部内高光 |

## 5. 签名组件：时刻带与刻度尺

| 组件 | 用途 | 规则 |
| --- | --- | --- |
| `common/TimeBand.vue` | 渐变满铺时刻带：日期星期、56px 等宽主时钟、0–24h 刻度尺、晨光橙指针、一句真实摘要 | 满铺三处：登录/注册左栏（静态刻度尺）、学生首页、管理端欢迎页（compact）。指针挂载时从 08:00 扫到此刻一次（420ms）；早于 8:00 / 晚于 22:00 时夹在窗口两端并给「今天还没到开放时间 / 今天已过开放时间」 |
| `common/TimeRuler.vue` | 时段刻度尺：08–22 占用块（深蓝）/「我的」占用块（渐变）+ 此刻指针 + 可点空档 | 教室详情页替换原时间轴；块类名保留 `timeline-slot`（E2E 依赖）。`clickable` 时空档 hover 显形，刻度尺上方还有常驻提示「点击空白时段，直接带入预约」保证首屏可发现；点击只回填预约弹窗，**不提交**；非当天传 `show-now=false` |
| `composables/useNow.js` | 全局 30 秒心跳（引用计数，无人订阅时停表） | 只在刻度尺 / 时刻带使用 |
| `composables/useCountUp.js` | 数字入场 0 → 目标（320ms rAF；reduced-motion 直接落位） | 只用于 KPI 与统计，首次拿到数据时播一次 |

## 6. 动效规范

| 语法 | 规格 | 用在哪 |
| --- | --- | --- |
| `.reveal` | `reveal-up`：opacity 0→1 + 上移 6px，220ms，`both` | 页头、内容面、首屏区块（每页一次） |
| `.stagger` | `animation-delay: calc(var(--i, 0) * 22ms)`，上限 12 项 | 教室卡片、快捷入口等重复对象 |
| `.page-swap` | 路由切换 opacity + 6px，220ms，`out-in` | 学生 / 管理端 `<router-view>` |
| `.is-leaving` | 180ms 淡出后再刷新列表 | 我的预约取消、审核行离场 |
| `.status-cell.is-updated` | `pill-flash` 一次，1.2s | 状态被改写后的一次提示 |
| `.press:active` | `scale(.98)` | 主按钮按下 |
| `.needle-in` | 指针从 08:00 扫到此刻，420ms | 时刻带 / 刻度尺挂载 |
| `.sheen` | 玻璃面高光扫过一次（600ms） | 仅登录面板与欢迎页 hero，各一次 |

硬约束：入场只动 `opacity` 与 `transform`（不触发布局重排）；单页入场总时长 ≤ 420ms；禁止 `infinite` 常驻动画（脉冲点仅存在于「正在思考」这类真实进行中状态）；`prefers-reduced-motion: reduce` 时全部动画时长/延迟压到 0.01ms（`web/e2e/specs/42-motion.spec.js` 两条用例守住两端）。

## 8. 已消除的 AI 默认外观（对照 2026 趋势报告）

| 被点名的 AI 痕迹 | 本项目做法 |
| --- | --- |
| SaaS 卡片套装（同款圆角卡 + 同一枚柔和灰阴影堆叠） | 内容面统一玻璃 + 差异化深度（近阴影 + 远期品牌投影 + 落地投影），满铺区用渐变而不是卡片 |
| 白底 + 紫蓝渐变（最常见的 AI 默认配色） | 主色是夜蓝→天蓝→薄荷青的冷色渐变，暖色只做「此刻」指针与 CTA，冷灰底改为浅蓝极光底 |
| 全大写 eyebrow、词间中点 `·`、按钮粘箭头 | 全部移除（历史轮次已清理，本轮继续守住） |
| 字号平板化（12/13/14/15 混用、标题不敢大） | 7 档字阶 + 44/56px 展示字号，标题与正文对比 ≥ 3× |
| 处处圆角 + 处处阴影 | 圆角 16/10/8 三档，阴影四档且只在浮起物上；表格与输入框不叠阴影 |
| 常驻呼吸 / 无限动画 | 只允许真实进行中状态（AI 思考脉冲），其余动画一次性 |

## 9. 约束与回归

- 不改业务规则、数据库结构、接口协议与依赖（不引入 WebFont、不新增 npm 包）。
- 保留 E2E 依赖选择器：`.page-title`、`.room-card`、`.room-name`、`.room-no`、`.status-cell`、`.thinking`、`.ai-plan`、`.chart-box`、`.stat-item`、`.quick-card`、`.chat-msg.user` / `.chat-msg.ai`、`.login-btn` 等。
- 回归顺序（复位种子 → 清缓存 → lint/build → E2E）。复位种子必须走容器内 `source` 并显式 `--default-character-set=utf8mb4`，否则中文会按管道编码二次编码落成乱码：

```powershell
docker compose cp database/init_db.sql mysql:/tmp/init_db.sql
docker compose exec -T mysql sh -lc 'mysql -uroot -proot --default-character-set=utf8mb4 reservation < /tmp/init_db.sql'
docker compose exec -T redis redis-cli FLUSHALL
cd web; npm run lint; npm run build
npx playwright test --project=chromium
node scripts/a11y-acceptance.mjs
```

- 交付口径：`npm run lint` 0 警告、`npm run build` 通过、Chromium E2E 全绿（含 `42-motion.spec.js`）、`web/scripts/a11y-acceptance.mjs` 15 pass + 1 info、README 截图重拍（`docs/images/01-login.png`–`08-ai-chat.png`）。

## 10. 与前三版的区别

| 维度 | 排课表式 | 墨蓝门牌 | 时刻带 | 晨光玻璃（当前） |
| --- | --- | --- | --- | --- |
| 色彩 | 近白 + 少量蓝 | 墨蓝单色 + 冷灰 | 墨蓝满铺 + 暖指针 | 夜蓝→天蓝→薄荷青渐变 + 浅蓝极光底 + 晨光橙 |
| 层次 | 细线分区 | 留白 + 白面 | 留白 + 白面 | 玻璃材质 + 四档深度 + 满铺区 |
| 字号 | 12–28 混用 | 6 档（最大 28） | 7 档（52 例外） | 7 档 + 44/56 展示字号 |
| 卡片 | 全部去卡片 | 重复对象用白面 | 白面 | 玻璃面 + 类型渐变条 + 不等宽 bento |
| 观感 | 扁、灰、像表格 | 稳、干净、偏素 | 稳 + 一点光 | 有光、有材质、大字对比，接近现代产品站 |
