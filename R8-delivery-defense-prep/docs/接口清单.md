# 接口清单（R8 最终交付版）

> 适用工程：`R8-delivery-defense-prep/code/reservation-server`（Spring Boot 3.2.10，Knife4j 在线文档：`http://localhost:8080/doc.html`）
> 本清单与源码控制器一一对应，为 R8 交付的权威接口口径；后续变更需同步更新本清单。

## 一、通用约定

| 项 | 约定 |
|---|---|
| 基路径 | `http://localhost:8080/api` |
| 请求/响应 | JSON（`Content-Type: application/json; charset=utf-8`） |
| 鉴权 | 除「登录/注册」外，所有接口需携带请求头 `Authorization: Bearer <token>` |
| 统一返回 | `Result`：`{ "code": 200, "message": "操作成功", "data": {} }`；`code!=200` 时前端统一弹错误提示 |
| 错误码 | 401 未登录/Token 失效、403 无权限/账号禁用、400 业务校验失败、500 系统异常 |
| 分页参数 | `page`（默认 1）、`size`（默认 10），返回 `{ records, total, page, size }` |
| 时间格式 | 日期 `yyyy-MM-dd`；时间 `HH:mm`；日期时间 `yyyy-MM-dd HH:mm:ss` |
| 状态码 | 预约：0-待审核 1-已通过 2-已驳回 3-已取消；用户状态：0-禁用 1-正常；教室：0-停用 1-启用；类型：0-普通 1-多媒体 2-机房；角色：0-学生 1-管理员 |

## 二、用户模块 `/api/user`

| 方法 | 路径 | 说明 | 权限 | 参数 |
|---|---|---|---|---|
| POST | `/login` | 登录 | 公开 | body：username / password / role |
| POST | `/register` | 学生注册（角色固定为学生） | 公开 | body：username / password / confirmPassword / name / studentNo / phone(选填) / email(选填) |
| GET | `/info` | 当前用户信息 | 登录 | - |
| GET | `/stats` | 当前用户数据概览（预约总数/进行中/近7日/收藏） | 登录 | - |
| PUT | `/info` | 修改个人资料（姓名/手机/邮箱） | 登录 | body：name / email / phone |
| PUT | `/password` | 修改密码（校验旧密码） | 登录 | body：oldPassword / newPassword |
| GET | `/manage` | 用户管理分页（关键词/角色/状态筛选） | 管理员 | query：page, size, keyword?, role?, status? |
| PUT | `/manage/{id}/status` | 启用/禁用用户（0 禁用 / 1 正常，禁止操作自己） | 管理员 | body：status |
| PUT | `/manage/{id}/password` | 重置用户密码为 `123456` | 管理员 | - |

## 三、教室模块

### 3.1 学生端 `/api/classroom`

| 方法 | 路径 | 说明 | 权限 | 参数 |
|---|---|---|---|---|
| GET | `/list` | 教室分页（关键词/楼栋/类型/日期实时状态筛选） | 登录 | query：page, size, keyword?, building?, type?, date? |
| GET | `/{id}` | 教室详情（含当日已通过预约时段与实时状态） | 登录 | path：id；query：date? |

### 3.2 管理端 `/api/classroom/manage`

| 方法 | 路径 | 说明 | 权限 | 参数 |
|---|---|---|---|---|
| GET | `` | 教室管理分页 | 管理员 | query：page, size, keyword?, building?, type?, status? |
| POST | `` | 新增教室 | 管理员 | body：name / building / roomNo / capacity / type / equipment |
| PUT | `` | 修改教室 | 管理员 | body：id + 上述字段 |
| DELETE | `/{id}` | 删除教室（存在关联预约时拒绝） | 管理员 | path：id |
| PUT | `/{id}/status` | 启停教室（0 停用 / 1 启用） | 管理员 | path：id；body：status |
| POST | `/batch-status` | 批量启停教室 | 管理员 | body：ids / status |

## 四、预约模块 `/api/reservation`

| 方法 | 路径 | 说明 | 权限 | 参数 |
|---|---|---|---|---|
| GET | `/conflict` | 冲突检测（前端双重校验第一层；公式：新开始<旧结束 AND 新结束>旧开始，仅与已通过比较） | 登录 | query：classroomId, date, startTime, endTime |
| POST | `` | 提交预约（后端二次冲突检测兜底；初始状态待审核；禁止过去日期；开始<结束） | 登录 | body：classroomId / reserveDate / startTime / endTime / purpose |
| GET | `/mine` | 我的预约分页（状态筛选） | 登录 | query：page, size, status? |
| PUT | `/{id}/cancel` | 取消预约（仅自己的待审核/已通过；开始前 1 小时内禁止） | 登录 | path：id |
| GET | `/manage` | 预约管理分页（状态/日期/关键词/教室筛选） | 管理员 | query：page, size, status?, startDate?, endDate?, keyword?, classroomId? |
| GET | `/export` | 导出预约记录 Excel（上限 10000 条） | 管理员 | query：status?, startDate?, endDate?, keyword?, classroomId? |
| PUT | `/{id}/audit` | 审核预约（仅待审核可审；通过前复查冲突；驳回必填备注） | 管理员 | path：id；body：status(1通过/2驳回) / auditRemark(驳回必填) |
| POST | `/batch-audit` | 批量审核（仅待审核参与；通过前逐条复查冲突，冲突整批拒绝） | 管理员 | body：ids / status / auditRemark(驳回必填) |
| GET | `/calendar` | 日历区间数据（区间跨度 ≤366 天） | 登录 | query：classroomId?, startDate, endDate |

|---|---|---|---|---|

| GET | `/list` | 我的收藏列表 | 登录 | - |

## 六、统计模块 `/api/stats`（管理员）

| 方法 | 路径 | 说明 | 参数 |
|---|---|---|---|
| GET | `/usage-rate` | 各教室预约使用率（已通过时段占开放时长比） | query：startDate?, endDate? |
| GET | `/trend` | 近 7/30 日预约趋势（全部状态计数） | query：startDate?, endDate? |
| GET | `/time-distribution` | 时段分布（按开始时段统计已通过预约） | query：startDate?, endDate? |

## 七、AI 能力模块 `/api/ai`（登录即可；`ai.enable=false` 时返回 `enabled=false` 友好提示，不阻断业务）

| 方法 | 路径 | 说明 | 参数 |
|---|---|---|---|
| POST | `/recommend` | 智能教室推荐 Top3（基于当前登录用户历史习惯+实时空闲；只读） | body 兼容（userId 忽略，以登录用户为准） |
| POST | `/parse-reservation` | 自然语言预约解析 → 结构化参数 | body：input |
| POST | `/chat` | 场景限定智能问答（无关问题返回预设话术） | body：question |
| POST | `/compliance-check` | 预约用途合规校验（只提示不改状态，审核仍由管理员手动执行） | body：purpose |
