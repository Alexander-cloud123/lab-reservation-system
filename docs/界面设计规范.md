# 界面设计规范：墨蓝门牌体系

本轮视觉重做的母题是**墨蓝门牌**：一套介于「高校教务系统」与「企业工作台」之间的界面语言，用墨蓝（`#1b3f8f`）承载身份与操作，用门牌编号（`A101`、`B201`）承载教室标识，其余一律退成冷灰白面与留白。它要解决上一版的问题：界面靠细线与标签撑信息量，结果既扁又乱，字号与颜色失控。

## 1. 设计原则

1. **结构靠留白，不靠细线。** 分区由 32px 留白与 13px 小标题完成，不画分割线；`--line` 只用于控件描边、表格行分隔与卡片边界。
2. **门牌编号是唯一记忆点。** 教室编号用 26px 高的描边门牌（`.code-block`）呈现，等宽数字对齐；不再给编号加底色块、图标或彩色标签。
3. **颜色只出现在该出现的地方。** 页面 95% 是白面与冷灰；墨蓝只给主操作、选中态与图表主序列；语义色只用于状态药丸与提示，不铺面积。
4. **字号只有 6 档。** 12（辅助）、13（正文与表格）、15（小标题与卡片名）、17（区块标题）、22（数字强调）、28（页面标题）。任何新样式不得引入第 7 档。
5. **卡片只用于重复对象。** 单条信息不装盒子；教室卡片、会话行这类「同一类对象重复出现」才用内容面（`.surface`）。一页最多一张主内容面。
6. **动效只回应用户动作。** 悬停改描边与底色、浮起改阴影档位；不做入场动画、不做呼吸式装饰；`prefers-reduced-motion` 下关闭全部过渡。
7. **既有约束优先。** 不改业务规则、接口、路由与文案语义；E2E 依赖的类名与可访问性语义全部保留。

## 3. 公共原语

| 原语 | 用途与规格 |
| --- | --- |
| `.page-container` | 页面容器：限宽 1200、页边距 `32px 32px 48px`、水平居中。 |
| `.page-head` | 页头三段式：`.page-title`（28/600）+ `.page-sub` / `.page-tip`（13 灰）；靠 24px 间距与内容面分开，不画底线。 |
| `.surface` | 内容面：白底 + 1px 描边 + 12px 圆角 + 24px 内距 + 一档极浅阴影。一页最多一张。 |
| `.section` / `.section-title` | 内容面内的分区：32px 留白分隔，小标题 13/600；无 border-top。 |
| `.code-block` / `.plate` | 门牌编号：26px 高、1px 描边、6px 圆角、13/600 等宽数字；`.is-signal` 为墨蓝浅底品牌字（登录页 A101）。 |
| `.status-pill` / `.status-cell` | 状态药丸（全站唯一允许全圆角的元素）：22px 高、tint 底 + 6px 圆点 + 12 字；`.is-pending` / `.is-approved` / `.is-rejected` / `.is-canceled` / `.is-today`。模板里不要再嵌套 `.status-dot`，否则双点。 |
| `.search-card` / `.table-band` | 筛选条与表格容器：白面 + 1px 描边 + 12px 圆角，替代「每页一张 el-card」。 |
| `.stat-card` | KPI 数据面：白面 + 细描边；数字 28/600 等宽。 |
| `.empty-slate` | 空状态：白面内联块 + 一句可执行提示，不用默认插画。 |

Element Plus 统一覆盖：主色墨蓝并按色阶给 light-3/5/7/8/9 与 dark-2；控件高 36px、圆角 8px；表格表头 `#fafbfc`、行高 52px、去斑马纹与 `::before` 底线；控件内文字统一 13px（EP 默认 14px 会破坏六档字阶）。

## 5. 约束与回归

- 不改业务规则、数据库结构、接口协议与依赖。
- 保留 E2E 依赖选择器：`.page-title`、`.room-card`、`.room-name`、`.room-no`、`.status-cell`、`.thinking`、`.ai-plan`、`.chart-box`、`.stat-item`、`.quick-card`、`.chat-msg.user` / `.chat-msg.ai`、`.login-btn` 等。
- 回归顺序（复位种子 → 清缓存 → lint/build → E2E）。复位种子必须走容器内 `source` 并显式 `--default-character-set=utf8mb4`：用 `Get-Content | docker compose exec` 管道会把中文按管道编码二次编码，库里落成乱码，页面与 E2E 断言一起失真：

```powershell
docker compose cp database/init_db.sql mysql:/tmp/init_db.sql
docker compose exec -T mysql sh -lc 'mysql -uroot -proot --default-character-set=utf8mb4 reservation < /tmp/init_db.sql'
docker compose exec -T redis redis-cli FLUSHALL
cd web; npm run lint; npm run build
npx playwright test --project=chromium
```

- 交付口径：`npm run lint` 0 警告、`npm run build` 通过、Chromium E2E 全绿、`web/scripts/a11y-acceptance.mjs` 16 项通过、README 截图重拍（`docs/images/01-login.png`–`08-ai-chat.png`）。

## 6. 与上一版（排课表式）的区别

| 维度 | 排课表式（已废弃） | 墨蓝门牌（当前） |
| --- | --- | --- |
| 结构 | 靠 1px 细线与标签分区，扁平 | 靠留白与内容面分层，有浮起层次 |
| 颜色 | 近白 + 少量蓝，页面发灰 | 冷灰底 + 白面 + 墨蓝强调，对比明确 |
| 字号 | 12/13/14/15/16/20/22/28 混用 | 只 6 档 |
| 圆角 | 统一 6/4/2，控件方硬 | 12（容器）/ 8（控件）/ 6（小元素）/ 全圆（仅状态药丸） |
| 编号 | 浅灰底编号块 | 描边门牌，作为唯一记忆点 |
