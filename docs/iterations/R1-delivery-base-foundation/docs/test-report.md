## 四、过程中发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 登录/注册触库操作全部 500 | Docker Desktop 引擎中途退出，MySQL 容器停止，3306 无监听 | 重启 Docker 与容器；容器设 `--restart unless-stopped`；启动说明补充自愈提示 |
| 2 | 非法 JSON 返回 500 | `HttpMessageNotReadableException` 未被专门处理 | 全局异常新增 400"请求体格式错误"处理器 |
| 3 | 伪造 Token 返回 500（HTTP 200） | 拦截器仅捕获 BusinessException，Hutool JSONException 冒泡 | 拦截器对 Token 解析**一切异常**统一按 401 拒绝 |
| 4 | EasyExcel 3.4.0 构建失败 | 该版本在 Maven Central/阿里云镜像**不存在** | 采用 3.x 最新 3.3.4，已上报负责人裁决 |

## 五、遗留限制与说明

1. **浏览器点击走查**：本会话浏览器自动化空间不可用（`browser_use_space_disabled_or_unavailable`，非鉴权原因），登录/注册/路由跳转的实际点击流程**未做浏览器端走查**；已通过接口级（T01~T21）、代理链路（F5）、生产构建（F3）与守卫代码验证覆盖。负责人可在浏览器打开 `http://localhost:5173` 快速点验（见启动说明第 4 节）。
2. 前端路由守卫、401 跳转、角色拦截均为确定性代码逻辑，随 `npm run build` 编译通过；建议 R2 起在具备浏览器空间的会话中补做 UI 级回归。
3. 测试过程中注册的临时用户已在交付前清理，数据库恢复 spec.md 4.3 初始数据（5 用户）。
